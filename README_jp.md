# 多言語コンテンツリスクアナライザー

**多言語コンテンツリスクアナライザー（ローカルモデル版）**

[English](./README.md) | [简体中文](./README_zh.md)  | 日本語

**ローカル学習済みNLPモデル + ルールベースのフォールバックメカニズム**に基づく多言語コンテンツリスク分析ツールで、**TikTok / ショート動画 / コメント / テキストモデレーション**のシナリオに対応しています。

**毒性検出 / ヘイトスピーチ / 感情強度 / 政治的感度**など複数の次元にわたるリスク評価をサポートし、説明可能な分析結果を出力します。


## ✨ 機能

* 🌍 **多言語対応**

  * 英語 / 中国語 / 日本語 / 韓国語 / フランス語 / ドイツ語 / スペイン語など
* 🤖 **ローカルモデル推論**

  * 外部APIに依存しない
  * 企業内導入やプライベートデプロイに適している
* 🧠 **マルチモデル融合**

  * 感情分析
  * 毒性言語検出
  * ヘイトスピーチ検出
* 🛡️ **モデル失敗時の自動デグレード**

  * モデルが利用できない場合、自動的にキーワードルール分析に切り替え
* 📊 **説明可能なリスクスコアリング**

  * LOW / MODERATE / HIGH / SEVERE
* ⚡ **バッチ分析対応**
* 🧩 **モジュール設計、拡張容易**

## 🔍 リスク分析次元

| 次元            | 説明                     | 重み   |
| -------------------- | ------------------------------- | ------ |
| `toxicity`           | 攻撃的、不適切な言語 | 0.35 |
| `hate_targeting`     | ヘイトスピーチ、グループ攻撃    | 0.35 |
| `emotional_intensity` | 感情強度             | 0.20 |
| `political_relevance` | 政治的感度コンテンツ     | 0.10 |

**0から1までの包括的なリスクスコア**を出力し、リスクレベルにマッピングします。

---

## 🚦 リスクレベル

| リスクレベル | スコア範囲 | 推奨事項       |
| ---------- | ----------- | -------------------- |
| LOW        | `< 0.2`     | コンテンツは安全      |
| MODERATE   | `0.2 – 0.4` | モニタリングが必要  |
| HIGH       | `0.4 – 0.7` | 手動レビューが必要 |
| SEVERE     | `> 0.9`     | ポリシー違反の可能性 |

## 🧠 使用モデル

### 感情分析（多言語）

* `cardiffnlp/twitter-xlm-roberta-base-sentiment`

### 毒性検出

* メインモデル: `unitary/toxic-bert`
* バックアップモデル: `distilbert-base-uncased-finetuned-sst-2-english`

### ヘイトスピーチ検出

* `Hate-speech-CNERG/dehatebert-mono-english`
* 自動的にキーワードルール検出にデグレード

## 🚀 クイックスタート

### 1️⃣ 依存関係チェックの実行

```bash
python analyzer.py
```

プログラムは不足している依存関係を自動的にチェックし、インストールプロンプトを表示します。

---

### 2️⃣ 単一テキスト分析

```python
from analyzer import analyze_text

result = analyze_text("You're such an IDIOT! I hate you.")

print(result)
```

出力例（簡略版）：

```json
{
  "risk_level": "HIGH",
  "risk_score": 0.62,
  "dimensions": {
    "toxicity": 0.81,
    "hate_targeting": 0.55,
    "emotional_intensity": 0.74,
    "political_relevance": 0.0
  },
  "detected_language": "en",
  "confidence": 0.85
}
```

---

### 3️⃣ バッチ分析

```python

    "hello!",

    "你个二货"
]

results = batch_analyze(texts)
```

## 🧯 デグレードとフォールトトレランス

* ❌ モデル読み込み失敗 → 自動的にルール検出を有効化
* ❌ 単一モデルエラー → 全体の分析に影響しない
* ❌ テキストが短すぎる → 自動的に信頼度を調整

**本番環境での動作を保証“中断なし”動作**
